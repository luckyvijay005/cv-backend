## 🎯 Your Next Actions

### Immediate (This Week)

1. **Run Pipeline** (5 min)
   ```bash
   cd cv-backend
   python run.py --video ../training_footages.mp4 --output data/outputs/report.json
   ```

2. **Annotate Sample** (1–2 hours)
   - Open `data/labeled/interaction_labels.json`
   - Fill in 1–5 minute-long windows
   - Per student: mark "interacting" or "isolated"
   - See `PHASE_2_QUICKSTART.md` for example

3. **Validate** (1 min)
   ```bash
   python validate.py \
     --labels data/labeled/interaction_labels.json \
     --report data/outputs/report.json
   ```
   - Check accuracy ≥ 60%
   - If < 60%, try tuning `--proximity` threshold

4. **Document Results** (30 min)
   - Take screenshot of validation report
   - Note any issues or insights
   - Save to `data/outputs/validation_notes.txt`

### If Needed (Refinement)

- **Low accuracy?** Tune proximity: try `--proximity 60`, `70`, `100` and re-validate
- **Tracklet jumping around?** Lower `max_age` in `tracker.py` line ~30 from 30 → 20
- **Need more data?** Annotate 2–3 minutes instead of 1

## 🔁 The Validation Loop

If accuracy is too low, repeat:

```
Run pipeline (different parameters)
    ↓
Annotate sample
    ↓
Validate
    ↓
Check accuracy
    ├→ ✅ ≥ 60%? → Move to Phase 3
    └→ ❌ < 60%? → Adjust & retry
```

**Common Adjustments:**
1. Increase proximity threshold (P): 80 → 100 px
2. Lower max_age in tracker: 30 → 20 frames
3. Change approach_events weight in interaction_analyzer.py

## Key Learnings & Gotchas

### ✅ What You'll Validate

- **Detection**: Are people being found?
- **Tracking**: Are tracklet IDs stable?
- **Interaction**: Are isolation scores meaningful?

### ⚠️ Watch Out For

- Tracklet drift (ID jumping) → Lower `max_age` in tracker
- False isolation (occlusion counted as loneliness) → Raise proximity threshold
- Over-sensitivity → Increase isolation score threshold in `validate.py`

### 💡 Pro Tips

- Annotate during varied activity (not just lectures)
- Label outliers (very social vs very isolated) for contrast
- Process 2–3 annotation rounds if time allows
